# Travel Website (MERN Stack)

## Features
- User-friendly travel booking interface
- REST API for tours and guides
- Full-stack MERN implementation

## Tech Stack
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB

## How to Run
1. Clone the repo
2. Install dependencies: npm install
3. Run backend: npm start
4. Run frontend: npm start

## Future Improvements
- Authentication (JWT)
